# Hooks

This plugin ships **no active hooks**. Nothing runs on edit, on session start, or on stop.

The craft toolbox (impeccable) has an optional edit-time design check. To turn it on for one project, run `/design-hooks on`. The command asks first. It needs the craft engine (see `/design-doctor`). The reference is [`skills/craft/reference/hooks.md`](../skills/craft/reference/hooks.md).
